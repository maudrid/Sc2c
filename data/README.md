# Data from UQM 0.8.0

Gameplay data extracted from The Ur-Quan Masters 0.8.0 source code by `tools/extract/extract_uqm.py`. Don't edit these files by hand: change the extractor and run it again.

They contain nothing from the UQM content package (art, sound, music, dialogue, strings), which is under a separate Creative Commons license and downloaded by the game on first run. The few names they hold, such as creature labels, come from comments in the GPL source code.

See `docs/uqm-data.md` for what each file holds and how to regenerate and check them.
